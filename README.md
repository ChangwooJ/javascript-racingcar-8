# javascript-racingcar-precourse

## 우아한 테크코스 2주차 프리코스

## 구현할 기능 목록

### 1. 입력 기능
- [ ] n대의 자동차 이름들을 입력받는다.
  - n의 값은 결정하지 않고 입력되는 이름 개수에 의존한다.
  - 쉼표(,)로 구분된 문자열 형식으로 입력받는다.
- [ ] 시도할 이동 횟수를 입력받는다.
  - 1 이상의 숫자만 허용된다.

---

### 2. 자동차 정의
- [ ] 입력받은 이름 문자열을 배열로 변환한다.
- [ ] 각 자동차 이름이 1자 이상 5자 이하인지 확인한다.
- [ ] 입력받은 이름들로 자동차 객체를 생성한다.
- [ ] 각 자동차는 초기 위치를 0으로 설정한다.

---

### 3. 자동차 이동 시도 랜덤 함수
- [ ] 자동자가 움직이기 위한 0~9 사이의 무작위 숫자를 생성하고 반환한다.

---

### 4. 자동차 전진 여부 처리
- [ ] 생성된 숫자를 기반으로 각 자동차에 대해 전진 여부를 판단한다.
- [ ] 전진으로 판단되면 각 자동차에 `-`로 전진 상태를 추가한다.

---

### 5. 레이스 과정 출력
- [ ] 매 이동 시 자동차의 이름과 현재 전진 상태를 출력한다.  

---

### 6. 우승자 판별
- [ ] 모든 이동이 끝난 후 가장 멀리 전진한 자동차를 우승자로 선정한다.
- [ ] 우승자 이름을 배열로 반환한다.
- [ ] 공동 우승자가 존재한다면 모두 배열에 추가해 반환한다.

---

### 7. 우승자 출력
- [ ] `최종 우승자: `라는 문구와 함께 우승자를 출력한다.
- [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.  

---

### 8. 예외 처리
1. 자동차 이름 입력
  - 자동차 이름이 5자 초과 또는 빈 문자열인 경우
    - `"[ERROR] 자동차 이름은 1자 이상 5자 이하로 구성되어야 합니다."`
  - 자동차 이름이 중복되는 경우
    - `"[ERROR] 자동차 이름은 중복될 수 없습니다."`

2. 이동 시도 횟수 입력
  - 이동 횟수가 숫자가 아닐 경우
    - `"[ERROR] 시도할 횟수로는 숫자만 입력 가능합니다."` 
  - 이동 횟수가 양수가 아닐 경우
    - `"[ERROR] 시도할 횟수로는 양수를 입력해주세요."` 

3. 우승자 판별
  - 모든 자동차의 이동 횟수가 `0`인 경우
    - `"[ERROR] 우승자를 결정할 수 없습니다. 최소 이동 횟수가 1 이상이어야 합니다."`
